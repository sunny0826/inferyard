## 共同边界

只读诊断，不读取完整命令行/环境、不自动关闭应用，不改变正式测量、服务生命周期或停止条件。
缺测为 null 加原因，应用 RSS 合计不是可释放量；review 仅供向用户询问用途。
每个平台保留行为回归、隐私负向测试、原生场景与一次源码审查；不强加录像、固定审查人数或
重复性能门槛。帮助/版本/Schema 保持 lazy import，故障和取消只回收自有采集器。

若并行写者，先划分各平台采集器/测试所有权；共享契约、注册和文档由主执行者串行集成。
检查通过后本地英文提交，push/PR/merge/close 仍须分别获用户明确授权。
全部单元完成后删除此计划入口，规则保留主题契约，进度保留 backlog。
