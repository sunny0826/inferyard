# ADR 047：重跑不再因工具身份差异拒绝启动

状态：Accepted

## 背景

`load_rerun` 在父运行的工具版本、scorer、整包源码哈希或 `implementation_identity` 任一与当前不符时，拒绝启动。
比较阶段已经把 scorer 和实现身份记成条件；工具版本目前只在重跑入口拦截，比较条件里没有它。
未封存、不是单次运行、复用同一服务进程，也会拒绝。这些不是上面四项。

## 决策

重跑可以在下列四项与父运行不同时启动：工具版本、`selection.scorer_sha256`、运行身份、以及旧运行上的 `tool_source_sha256`。
运行身份以 [ADR 046](046-single-implementation-identity.md) 选定的那一条为准。ADR 046 未接受时，两个身份字段的差异都记入，不另做一道启动拒绝。

新运行仍标记 `relation = rerun`，并保留父运行标识。
比较新增 `run.tool_version` 条件。这四项有差异时，比较资格不成立，状态是差异，不是缺测。
不把差异写成允许差异。

下列门不放宽：父运行必须已封存且是单次运行；必须换一个新的服务进程；资产哈希；dirty；请求前后空闲；排空；温停与内存停。

## 后果

工具或 scorer 已经更新时，重跑命令会执行，不再在入口停下。
随后的比较不能把这次重跑说成与父运行同资格。
忽略比较记录、只看重跑已经跑完，会把不同工具下的结果当成同条件重复。
