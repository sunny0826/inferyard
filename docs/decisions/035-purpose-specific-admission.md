# ADR 035：按用途区分描述、执行与审核条件

状态：Accepted

## 决策

分别定义描述性差值与受控结论资格、诊断环境观测与正式准入、执行终态与评分完整性。
新 comparison v2/report v5 引入描述性观测；旧比较和报告按原版本读取。
新配置可显式冻结必需环境字段，旧正式计划保留原严格匹配；SafetyGuard 的显式环境停止独立执行。
孤立评分错误保留 unscorable 后继续收集，最终 partial/code3，不缩减分母。

clean 且加载配置一致、非冷启动的服务可复用，当次探测和身份仍核验。
新增 rerun/跨 workload 复用需要已核验引擎排空；原串行 native client_http 继续范围不扩大为引擎 idle。
逐题审核绑定题目、答案、规则和共享政策，只重审受影响项，不从失配整包签名自动投影批准。

## 理由与代价

用同一门槛处理观测、执行和审核会产生与目的无关的阻断，也会把评分失败误当模型未执行。
版本化分派和显式字段增加少量复杂度，换取当前功能与历史语义并存。
不采用强制可比、重置旧评分身份、自动重签或跨命令探测凭证。

详细优先级、哈希与复用范围见[按用途分派](../data-contract.md#按用途分派)。
