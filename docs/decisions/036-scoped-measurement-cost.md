# ADR 036：按职责绑定身份、持久化与校准适用域

状态：Accepted

## 决策

新运行记录 measurement/scoring/presentation 职责身份，同时保留完整源码摘要。
comparison v3/report v6 使用新身份和校准规则，旧版本按旧定义重算。
目录资产只绑定权重、索引、配置、tokenizer 和模板；旧全目录计划不改哈希。
Windows 请求期使用全量绑定哈希与原生 stamp 检查变化，预检/每 trial 的完整核验保留。

新运行移除无消费者的派生请求副本与列表，保留原始事件、已有同步与旧副本读取。
合适的完整总开销证据可独立成立，增量 ABBA 作为可选拆项诊断；复用域仍绑定测量实现、依赖、采集配置、工作量、输出、boot 与环境。
已核验量化谱系可提供 tokenizer 相等证明，缺证明不推断。

## 理由与代价

改展示文本不应改变测量等价判断，重复持久化和强制双校准也增加无关成本。
仅删除身份或工作量哈希会误授资格，因此采用明确职责清单与保守适用域。
不引入持久缓存、无界异步写入或无调度证据的线程；代价是新旧分派和更多来源说明。

精确清单、依赖和原始日志同步规则见[职责身份契约](../contracts/scoped-measurement-contract.md)。
