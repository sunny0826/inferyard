# ADR 045：报告里的重复全文改为同一份内容引用

状态：Accepted

## 背景

当前报告格式是 `report_format_version = 7`。工具只接受 v7。
一份报告里，题面、模型输出和参考答案会同时出现在逐题行、详情和 SVG 画廊里，HTML 再各嵌一份。
画廊和逐题 `svg_view` 都从该题输出现算。CSP 禁止外链脚本。报告必须离线自包含。

## 决策

新报告为 `report_format_version = 8`。工具只接受 v8。
每段题面、模型输出、参考答案在一份报告内只保存一次，以内容哈希标识。
逐题行、详情、画廊和 HTML 引用这个标识，不再各存一份可独立漂移的全文。

HTML 仍从这份报告内部的那一份文本显示。引用不出文件，不改成外链。
CSP 保持 `default-src 'none'`、`style-src 'unsafe-inline'`，`script-src` 只允许该次模板脚本的 SHA-256。
SVG 仍只对 `category = svg` 从那一份模型输出现算。解析失败仍降级为状态说明。
画廊仍是「SVG 生成展示 · 不评分」。原始输出仍以转义文本保留。
评分分母、六类质量和五种终态的展示语义不变。

v7 及更早的 HTML 不再由本工具核验或重渲染。浏览器打开那些文件不受影响。
从现有证据重新生成报告时，写出 v8，不改原证据。

## 后果

解析报告 JSON、指望题面或输出直接嵌在每一行里的读者，要改为按内容哈希取文。
已经生成的 v7 报告，工具不再接受。
页面上仍看得到题面、输出和画廊。自包含和 CSP 不放松。
