# ADR 034：命令内复用与显式预算快照

> 局部取代：当前格式读取、历史迁移/模板和主机状态边界以 [ADR 038](038-inferyard-current-format.md) 及其矩阵为准；其余决策与原始理由保留。

状态：Accepted

## 决策

评分身份、选中规则、结构 validator 及已核验离线字节在命令内复用，不跨命令缓存。
预算用 `token-budgets.v2.json` 明确 phase/case，只覆盖当次发送的 probe、非零预热及选中题。
旧位置数组按原规则读取，run 仍执行当次普通/流式探测。

## 理由与代价

重复读取与重复准备增加成本，却不增加独立证据；显式传递同次已验证对象可减少重复工作。
持久缓存或复用新打开路径的字节可能隐藏变化，因此不采用。
评分源码身份变化仍阻断 rescore 资格，返回稳定原因而不解释为篡改。

新增预算形状需要兼容分派，不改变请求、题序或分母。字段见[数据契约](../data-contract.md#命令内复用与预算快照)，职责身份拆分由 [ADR 036](036-scoped-measurement-cost.md)补充。
