# ADR 031：源码获取由一个宿主保管进程

状态：Accepted

## 决策

控制宿主只管理内存、原进程对象与有界管道；文件读写、下载和哈希由直接子进程承担。
子进程不得再创建后代。需要接手时继续调用同一宿主实例，保留原对象，不用数字 PID 重建所有权。
该库不管理模型服务，真实获取 CLI 尚未接入。

## 理由与代价

在控制宿主同步读写磁盘可能阻塞期限处理；硬杀父进程会丢失未知子进程的原引用。
线程封装不能保证阻塞 I/O 可中止。直接子进程隔离增加启动/管道成本，计入共同期限。
Windows 以原子入 Job 限制后代；退出或关闭结果未知时保留引用和待接手状态，不能宣称成功。

协议与现有预算见[宿主契约](../contracts/windows-source-host-contract.md)。是否接入真实用途见[backlog](../backlog.md)，不将库测试作为引擎构建通过。
