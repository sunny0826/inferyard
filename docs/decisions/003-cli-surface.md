# ADR 003：统一核验与命令分组

状态：Accepted。日期：2026-10-01。

## 决策

八个产物核验入口统一为 `verify --path DIR`，公开配置匹配并入 `--config`。内部沿用专用验证器；比较同时核验 comparison 与报告，无法识别、损坏或类型冲突均拒绝，不采用只核验 manifest 的回退。

公开操作使用 `public package/plan`，扩展使用 `extension freeze/run/replay`，服务诊断使用 `probe`。参数明确实验、多个报告来源、整体重跑以及扩展 spec/plan/packet 的输入角色。

保留旧命令和参数作为兼容入口；主帮助和文档使用规范语法。同一输入的新旧参数同时提供时拒绝。退出码、stdout JSON、原件保留和各动作输出目录语义不变。

本决策部分修订 [002](002-cli-architecture.md) 的命令名称限制；[001](001-unified-contract.md) 的唯一活动契约、显式迁移与测量资格规则不变。

## 理由与代价

统一入口减少相同核验意图的记忆成本；严格识别和专用验证避免遗漏语义重放、来源核验或报告完整性。兼容别名避免破坏已有脚本，代价是维护别名冲突和失败路径。

run/resume、report/compare、rescore/export/report 及两类开销协议分别保留，它们的输入、来源和资格约束不同。公开配置匹配不证明服务就绪；配置不匹配及开销阈值/绑定未通过仍退出 3，非法输入退出 2，损坏证据退出 4。

核验只读，不请求模型，不授予新的实测资格。完整语法与类型边界见 [CLI 接口](../cli-surface.md)。
