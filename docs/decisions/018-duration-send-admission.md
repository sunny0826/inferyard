# ADR 018：持续负载在客户端发送起点准入

状态：Accepted

## 决策

持续负载在 adapter 实际执行 generate 的客户端起点读取新鲜单调时间，
以同一值决定是否在冻结窗口内、登记 request_started 并设置响应的发送起点。
拒绝准入时不发 POST、不产生正式尝试；准入后取消保留正式终态并走原排空规则。

## 理由与代价

控制层提前登记后，异步任务可能排队到窗口外，造成准入数与按发送时间归组的计数不守恒。
扩大窗口、用早期时间回填或删掉末项都会改变测量方法，因此采用发送前回调。
请求身份写盘发生在客户端起点之后、HTTP 调用之前，开销计入请求耗时；该时间不冒充物理发包或服务端到达。

写盘失败保留 dirty；没有回调的固定请求保持原行为。精确边界和拒绝路径见[发送准入契约](../contracts/duration-send-contract.md)。
