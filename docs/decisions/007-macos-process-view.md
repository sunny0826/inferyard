# ADR 007：同次 macOS 身份核验共用新鲜进程文件视图

状态：Accepted

## 决策

一次 `verify_process` 内通过一次 `lsof` 全文件视图核验二进制、监听和 Metal 库；
每次完整核验重新读取，独立 `verify_listener` / `mapped_file` 调用仍单独新读。
保留前后启动身份、所有者、文件设备号/inode、哈希和唯一监听检查。

## 理由与代价

同次调用重复启动 `lsof` 增加成本，却不增加独立测量目标。调用局部共享消除重复查询，
不引入跨请求或全局缓存。全视图不是原子快照，不能证明整个窗口内文件表不变；前后身份检查仍必要。
这一改动不承诺总采集开销一定达到阈值。精确接口与限制见[同次身份视图契约](../contracts/macos-contract.md#同次身份视图)。
