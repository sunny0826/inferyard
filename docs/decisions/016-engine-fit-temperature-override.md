# ADR 016：显式冻结临时温度停止覆盖

状态：Accepted

## 决策

engine-fit 可在创建新计划时使用 `--skip-temperature-stop REASON`，冻结独立 plan.v3/run.v4。
原因参与哈希，温度上限为 null，温度读数仍采集，报告明示覆盖；不能在 run 中切换。
默认与旧计划仍为 85°C。其他停止、身份、主机锁、dirty、取消与排空继续执行。

## 理由与代价

明确的短诊断可能需要记录超过默认阈值的行为。将阈值随意设高会掩盖停止已暂停，
编辑旧计划会破坏来源，因此使用新定义和显式原因。代价是新增版本分派与更高的诊断风险。
旧授权不自动作用于新运行，两引擎比较须使用同一新计划。

内存覆盖由 [ADR 019](019-engine-fit-memory-override.md)独立补充；原因长度、字段约束与旧格式读取见[常用引擎契约](../contracts/engine-fit-contract.md#常用引擎扩展)。
