# ADR 001：单一活动契约与显式迁移

> 局部取代：当前格式读取、历史迁移/模板和主机状态边界以 [ADR 038](038-inferyard-current-format.md) 及其矩阵为准；其余决策与原始理由保留。

状态：Accepted。日期：2026-10-01。

## 决策

只维护一份活动数据契约，当前为 `schema_version = 3`。单次与实验是调度模式，共用事件、评分、样本、账本和封存结构；主程序不选择或隐式读取旧版本。

历史 v1/v2 原件保留，通过显式迁移转换到新目录。迁移核验封存哈希，保留原始字节、评分与测量身份、转换规则和缺测原因，不冒充重新测量或授予新的性能比较资格。

人工题包审核、来源核验、主机互斥和冻结停止条件继续有效。旧审核仅在原记录、原批准与内容等价可核验时继承，不改写审核人的签名或日期。

本决策取代早期 MVP 阶段和“双版本并存”的实现约定。后续 [002](002-cli-architecture.md) 调整源码组织，[003](003-cli-surface.md) 调整命令语法，均保留上述证据规则。

## 理由与代价

只合并版本号或 Schema 导出仍会留下不同的事件、评分与汇总通路；默认双读继续维护隐式分流。采用单一契约后，旧结果需一次显式迁移，正常执行、重建与比较共用解析规则。

删除旧结果会破坏来源，不作为精简手段。迁移补出的实验上下文须标为迁移生成；缺少原证据的字段保持缺测。平台执行控制仍独立，统一格式不扩大平台支持。

接口见[数据契约](../data-contract.md)，平台与实际证据见 [README](../../README.md)。软件和离线验收不构成新的模型实测。
