# 职责与事实源

关键身份与版本的事实在此处定义一次：评分器身份是 `scorer_hash()` 对固定源码文件列表、`jsonschema` 版本与 `unicodedata` 版本的 SHA-256，修订版身份在其上叠加 `scoring_revision.py` 字节；`analysis_id` 由来源绑定与生成者哈希派生（原始分析为 `trial-` 前缀，重评分为 `rescore-` 前缀）。当前格式版本：报告为 `studio-report.v1`（`schema_version = 3`，不再参与核验，旧报告 v1–v8 拒绝）、比较产物 `format_version = 5`（定义版本 `phase2.v3`）、重评分记录 `format_version = 1`，均要求 `schema_version = 3`。字段语义与格式规则见 [数据契约](../../../cli/docs/data-contract.md) 与 [报告契约](../../../cli/docs/contracts/report-contract.md)，不在这里复制。

`reporting/engine_fit*.py` 是 engine-fit 诊断产物与绑定核验的报告侧，职责归 [engine-fit 引擎诊断](../engine-fit.md)，不在本参考展开。
