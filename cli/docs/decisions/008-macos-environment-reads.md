# ADR 008：macOS 环境查询与同次换页读取

状态：Accepted。换页来源和环境每次全量新读由 [ADR 042](042-environment-collection-slim.md) 修订。同次换页共用一个读取窗口、失败不沿用旧值，这两条仍有效。

## 决策

CPU 型号用有界的原生 `sysctl` 字符串读取；同一次 counters 调用的 Swapins/Swapouts
共用一个 `vm_stat` 快照和读取窗口。电源、启动身份与各次新鲜性要求保持。

## 理由与代价

重复启动命令增加采样开销。局部共用快照只减少有证据支持的重复工作，不缓存跨周期状态。
CPU 与换页可来自不同窗口，不能称整个资源包为原子快照。共同身份失败使换页两行缺测，
单字段失败只影响对应行；截断、计数回退或来源变化不沿用旧值。

接口见[环境与换页契约](../contracts/macos-contract.md#环境与换页读取)。总开销与资格仍按完整测量处理。
