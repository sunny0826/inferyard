# ADR 055：本地五引擎正式串行测评

状态：Accepted。日期：2026-10-20。实现与真机覆盖分别验收。

## 决定

新增 `local-engine-config.v1`，在 v3 外壳下显式选择
`local_openai_v1` 及 llama-cpp、MLX-LM、vLLM、SGLang、LM Studio 家族。
复用正式 trial、评分、五终态、journal 和报告，不把 engine-fit 诊断升级成正式结果。
旧 adapter、旧模型文件哈希和既有 native 同 workload 续测语义保持。

目录模型使用版本化文件清单摘要，Python 安装使用完整运行环境快照。
它们不占用旧 `model.sha256` 或 `engine.binary_sha256` 字段。
配置准备冻结资产，绑定核验实际服务；CLI 始终不启动或停止模型服务。
Studio 的启动所有权属于独立执行阶段，不能由一次成功绑定推导。

客户端合法终态、队列空闲和引擎内部排空分别记录。
沿用 `native/client_http`，增加 `local-engine-observation.v1` 及逐请求队列观察。
成功 HTTP 请求只有在请求后身份与队列复核通过后才能保存清理回执。
没有逐请求释放协议时，超时、取消或观察失败后即使队列为零也保留 dirty。

两个正式题包分别冻结和封存。跨题包缺少强排空证明时必须核实旧进程退出、
替换服务并重新绑定，不能通过两条独立 run 命令回避转换。
同 workload 正常串行继续仍只证明客户端完成，不增加受控性能比较资格。

## 取舍

选择现有 native 生命周期加显式 profile，避免新增第三套执行器或通用代理网关。
沿用正式普通与流式解码，MLX 使用新的正式入口协议；
旧 engine-fit MLX 入口及其来源哈希不变。
模板原件、实际模板、token 预算和实际生成参数分开核验；无法观察的值保留缺测原因。

安装完整库存复核有可观成本。请求边界复核完整身份，
异步队列观察中的校验放到线程，周期安全检查持续检查资源和传感器。
全部成本属于本次测量，不继承旧资格；绑定 PID 的资源采样不冒称整个 worker 树。

参数、文件闭包与失败读取规则以[本地引擎契约](../contracts/local-engines.md)为准。
证据解释遵循[血缘规则](../data-contract.md#证据血缘与比较结论)。
