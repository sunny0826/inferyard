# 指标验收用例

本文件收录[指标定义](metrics.md)与[资源、稳定性与条件指标](metrics-resources.md)的手算与故障验收用例，不是 catalogue 的生成源。

## 7. 关键手算与故障验收

这些是指标 fixture，不是正式模型成绩；优先测计量风险，不用重复实现细节的低价值测试堆数量。

| 用例                                                                        | 精确预期                                                                                                   |
| --------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| 4 个有效请求，3 完成 1 超时；2 题通过；完成中 1 题 length 结束且正确                 | 完成率 3/4，超时 1/4，质量 2/4，耗尽 1/4；超时不进完成耗时分布，length 不改执行完成                             |
| 上述计划再增加 1 个取消请求                                                   | P=5、D=4；仍展示有效子集计数，完整质量率与整包差值 null；不能假装仍是完整 4 题测试                            |
| 2 道 JSON 题每题 3 字段：第一题 2 字段正确且 Schema 合法，第二题解析失败             | 解析率 1/2、Schema 率 1/2、字段准确率 2/6、整题通过 0/2；坏 JSON 字段不能从分母删去                               |
| 首 reasoning 200ms，首答案 300ms，完整结束 1200ms，usage 输出 12token，2 个内容块 | 首内容 200ms、首答案 300ms、E2E1200ms、端点吞吐 10token/s；ITL/prefill/decode 无证据则 null，不用块数 2 作 token 数 |
| 输出预算 length 完整结束但空答案                                              | C 且 budget_exhausted；质量 fail；首答案 null/no_answer_event，E2E 有效                                         |
| 分类 2 类，真值 `[A,A,B,B]`、预测 `[A,非法,B,超时]`                                 | 固定无效预测列；A/B 各 TP=1、FN=1、FP=0，各 F1=2/3，macro-F1=2/3，整题正确率 2/4                               |
| CPU 计数增量 1.5 秒、墙钟 0.5 秒                                                 | 单核口径 300%；若归一化到 12 逻辑核为 25%，应另名且记录 12 来源                                                |
| 请求 0–2 秒，仅 0.5/1.5 秒有 CPU 累计样本，计数增量 1 秒                           | 观测区间 1 秒、CPU 利用率 100%、覆盖 50%；整请求 CPU 时间 null，不能报利用率 50%                                    |
| 本地预检拒绝超长输入；另一合法请求发出后服务返回 413                         | 前者 not_executed，后者 F/http_error，后者进入完成/质量分母；二者分别展示拒绝原因                            |
| 失败请求留下合法且正确 JSON 后断流                                            | Q03/Q04/Q05 正式成功贡献均为 0；部分输出解析结果只在诊断区展示                                               |
| 5 个延迟样本                                                                 | 展示样本和中位/范围，P95=null/insufficient_samples；不靠插值生成 P99                                        |
| 计量能量计数从 95 到 5、量程 100μJ 且确定最多一次回绕                            | 增量 10μJ；无法排除多次回绕或重置时为缺测，不直接算−90μJ                                                    |
| 2 成功 1 失败消耗总 30J，计量窗口均完整                                         | 15J/成功任务；若 0 成功则 null，失败能量不能剔除                                                              |
| 采样有预热 99GiB 极值、正式 8GiB、结束后 99GiB                                  | 正式 RSS 观测峰值 8GiB；边界跨越样本不偷算入正式窗口                                                          |
| 3 轮同一 40 题                                                                 | 40 个题目 cluster、120 次尝试；不是 120 道独立题；第 2 轮中断不能取后补成功拼装完整 3 轮                            |
| 旧包没有 prefill 计时                                                         | 迁移后报告 prefill=null/evidence_missing；原数据及 hash 不改，不重新调用模型补测                              |
| 评分算法升级后显式重评分                                                    | analysis_id 和评分版本变化，原 run_id/响应不变；旧评分仍可读；不同规则默认禁止直接质量差值                   |
