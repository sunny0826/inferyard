设计依据与实现差异

依据「职责与事实源」的引擎生命周期、下载任务、CLI 安装与预置资产、绑定存活提示；「运行路径」2 / 5 / 6 / 8 / 9；引擎状态机及「约束与失败行为」。原生页面已按本原型实现四区（models.go / models_table.go / models_engine.go）：引擎下载经 CreateEngineDownload 进入统一任务列表，取消复用 CancelDownload。

引擎传输接口仍不提供字节读数，引擎任务的字节与速率保持 null 并带 progress_reason；模型下载完成由 CLI 结果或 source.json 收尾，正式文件发布后按实测字节收尾。
