下载目录名

设置后，新下载任务自动使用基础名，无需每次填写。

仅允许字母、数字、点、下划线、连字符；不能为空，也不能全为点。默认值为 model / engine。

名称被占用时自动追加序号，如 model-2、model-3；不覆盖已有目录。实际名称显示在下载任务详情中。
