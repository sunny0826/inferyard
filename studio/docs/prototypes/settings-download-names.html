下载目录名 下载创建时使用的基础名

使用默认值
默认 model。字段 model_download_name目录名只允许字母、数字、点、下划线与连字符，不能全为点。
默认 engine。字段 engine_download_name目录名只允许字母、数字、点、下划线与连字符，不能全为点。

校验规则与示例

model✓ 合法 · 默认值
qwen-2.5✓ 合法 · 连字符
prism.b10743✓ 合法 · 点
我的模型✗ 含中文等不允许字符
../models✗ 含斜杠
...✗ 全为点
a b✗ 含空格

非法示例均显示同一条字段错误：目录名只允许字母、数字、点、下划线与连字符，不能全为点。（正则 ^[A-Za-z0-9._-]+$，且去除点后不能为空；不能为空。）

下载创建从设置读取基础名：模型页不再逐次询问目录名；同名目录已占用时自动依次追加 -2、-3……实际使用的目录名显示在下载任务详情（示例：基础名 model 已占用 → 实际目录名 model-2）。
适用范围与保存规则

模型下载（含填写凭据环境变量名的下载）与引擎下载均使用此处基础名；预置模型与预置引擎下载同样适用。

保存设置不创建目录，也不移动已有目录；设置文件沿用现行 0700/0600 权限原子写回。序号在下载创建时按目录占用情况决定，保存时不预检。

原型以 docs/subsystems/studio-panel.md 为行为依据；「下载目录名」区块对应实施方案步骤 1（UserSettings 新增下载目录名字段）。本页按钮模拟事件快照，无计时器伪造进度。
设计依据与实现差异

字段与默认值：UserSettings 新增 model_download_name / engine_download_name，默认 model / engine；校验沿用目录名规则（^[A-Za-z0-9._-]+$，不能全为点），设置文件沿用 0700/0600 权限原子写。

行为：模型下载（含凭据环境变量路径）与引擎下载从设置取基础名，目录占用自动追加 -2/-3，实际目录名显示在下载任务详情；模型页（现「模型」页）移除逐次询问的「新目录名」输入。

原型取舍：保存按钮按卡分组（每组一个主操作）；目录名不能为空，遵守 validName 规则；「生效值与探测状态」未展示下载名（方案未明确 EffectiveSettings 是否新增字段）。
